# Artifact Hashing and Binding

## Suggestion

Let a declaration bind to an immutable file, canonical text, a defined page
region, a C2PA manifest, or a source-system version while allowing scope-based
declarations when stable bytes do not exist.

## Before implementation

Specify canonicalisation, algorithms, dynamic-content handling, derivatives,
missing artifacts, revalidation, and clear labels for byte-bound versus
scope-bound claims.
