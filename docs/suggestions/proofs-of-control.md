# Proofs of Control

## Suggestion

Support factual evidence that a claimant controlled a mailbox, account, domain,
artifact location, or signing key at a stated time. Keep organisation authority
as a separate, stronger question, and let claimed parties issue tamper-evident
declaration links.

## Before implementation

Design challenges, expiry, rechecking, recovery, key rotation, delegated roles,
privacy, disputes, and exact human-readable labels. Keep self-service checks
free while treating managed continuous monitoring as an optional service.
