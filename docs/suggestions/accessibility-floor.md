# Accessibility Floor

## Suggestion

Guarantee a neutral, high-contrast, low-bandwidth route for every core task,
including about, help, support, builder, profile, directory, checker, and account
settings, regardless of decorative themes.

## Before implementation

Validate keyboard use, focus, screen readers, reduced motion, contrast, reflow,
zoom, print, CJK, RTL, mixed languages, non-colour status, and CAPTCHA alternatives.
