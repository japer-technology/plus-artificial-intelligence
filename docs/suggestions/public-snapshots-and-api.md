# Public Snapshots and API

## Suggestion

Publish unauthenticated, cacheable, versioned registry snapshots with hashes,
pagination, incremental change feeds, stable schemas, and an API for profiles,
declarations, search, verification, publication, and revocation.

## Before implementation

Separate read and write paths, version from launch, define privacy-safe fields,
authorization, audit logs, moderation, rate limits, and deterministic exports.
