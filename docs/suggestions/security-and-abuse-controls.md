# Security and Abuse Controls

## Suggestion

Protect hosted accounts, user-authored text, links, registries, mail services,
uploads, APIs, and verification fetches against takeover, injection, phishing,
spam, scraping, malware, denial of service, and internal-network access.

## Before implementation

Threat-model each service and define authentication, authorization, output
encoding, CSP, URL policy, network isolation, rate limits, recovery, and response.
