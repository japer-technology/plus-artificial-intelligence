# Machine-Readable Assertions

## Suggestion

Expose a versioned `+AI` assertion through page metadata, JSON-LD, a manifest,
or `/.well-known/plus-ai.json` so software can find the responsible party,
scope, AI role, specification version, and status.

## Before implementation

Align every representation to one schema and define discovery, validation,
extension, canonicalisation, privacy, and stale-data behaviour.
