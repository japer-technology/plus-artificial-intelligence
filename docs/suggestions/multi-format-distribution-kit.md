# Multi-Format Distribution Kit

## Suggestion

Provide the mark and explanation as plain text, linked names, HTML, Markdown,
SVG/PNG badges, monochrome print, QR, document footers, slides, captions,
packaging references, social cards, and accessible short or long copy.

## Before implementation

Define canonical wording, accessibility, export sizes, version links, brand
rules, offline behaviour, and tests that every format preserves meaning.
