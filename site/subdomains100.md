# Sub-Domains — The Essential 100

If only 100 sub-domains from [subdomains.md](subdomains.md) can exist, these are the 100. Selection rules: the site must function (utility names first); every name must read as a complete sentence when spoken with the domain; one name per idea, so near-duplicates were dropped in favour of the strongest phrasing; the core accountability message is covered in every voice (I, we, human); and one flagship phrase for each of the sixteen most-spoken languages in the wishlist keeps the reach global.
